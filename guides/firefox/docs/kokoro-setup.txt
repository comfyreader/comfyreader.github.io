COMFY READER KOKORO SETUP AND UPDATES
Updated November 4, 2026

DOWNLOAD
https://github.com/comfyreader/comfyreader.github.io/releases/tag/kokoro-2026.11.04
Choose Comfy-Kokoro-Setup.zip. Use the same download for a new installation or
an update. Install Comfy Reader separately through Chrome Web Store or Firefox
Add-ons. The ZIP contains only the optional local speech service.

INSTALL OR UPDATE ON WINDOWS
1. Download and extract the complete ZIP, then double-click Setup.cmd.
2. Setup detects recognized installations or offers a new per-user folder.
   Finish or cancel any active recording before updating. Existing service
   settings are preserved and replaced files are backed up. Customized or
   unfamiliar service code is preserved instead of overwritten.
3. Choose whether Kokoro starts automatically when you sign into Windows.
4. In Comfy, open Speech setup, select Automatic or Local Kokoro, allow local
   access if requested, test the voice and save the settings.
   Default speech address: http://localhost:20071/speech

Windows 10/11 x64 Intel/AMD only. Allow several GB of free disk space. Includes
private Python, Kokoro models and voices, Misaki, its English model and the
eSpeak fallback. No separate Python or eSpeak MSI is needed. If the Microsoft
Visual C++ x64 runtime is missing, Setup asks before downloading its signed
installer directly from Microsoft. That prerequisite needs Internet access and
may require administrator approval. The Comfy installer itself is not signed.

The default new installation folder is %LOCALAPPDATA%\ComfyReader\Kokoro.
To select a specific existing folder or port, open PowerShell in the extracted
setup folder and run:
  .\Setup-Kokoro.ps1 -InstallRoot 'C:\path\to\kokoro' -Port 20071
Keep the installed folder. Use Start Kokoro.cmd, Stop Kokoro.cmd and
Kokoro Status.cmd in that folder. Browser-store updates do not update Kokoro.
Download the current speech package and run Setup.cmd again for service updates.

MISAKI AND PRONUNCIATION
Misaki turns English text into speech sounds using sentence context before
Kokoro creates the audio. It runs inside Kokoro's worker, not as a separate
service. Comfy's Reader profile substitutions run first. Use them for
abbreviations, symbols and personal preferences. Broad read/reed/red rules can
remove helpful context. Pronunciation is not perfect. The worker includes
targeted past/present handling for misread.

Try these sentences using Local Kokoro:
Yesterday, I misread the instructions. Today, I often misread small print.
I have read the record. I want to read it again and record my answer.
We live near the theater. We watched a live concert.
The wind was strong. Please wind the clock.

WARM-UP AND CPU THREADS
The first recording after starting Kokoro loads the model and pronunciation
tools; it can take longer. Later recordings usually start sooner. Stop and
cancel ends the current generation worker, so the next recording may need to
warm up again. Longer passages still take longer to prepare.

The service-settings.json file in the installed folder has cpuThreads (1-8).
The default uses up to 8 available CPU threads. To tune it, stop Kokoro, edit
cpuThreads, save, then start Kokoro. Compare 4 and 8 using the same voice and
passages, including both short and long text. Compare cold runs separately
from warmed-up runs. Other apps and games can affect the results; a higher
number is not always faster. Keep the value that works best on your computer.
The playback speed setting in Comfy changes listening speed, not generation
CPU threads. Browser speech is available without the local service.

CONNECTION AND TROUBLESHOOTING
Local access shows browser permission; Connected shows service availability.
Expand Connection settings to change the address or test the connection.
The published Chrome extension is allowed by default. Firefox uses its
restricted localhost integration. Never configure a wildcard origin.

To check the default service in PowerShell:
  Invoke-RestMethod -Uri 'http://127.0.0.1:20071/health' -TimeoutSec 10
Expect ok: True and engine: Kokoro. A health response does not prove voice
generation works; also use Test voice and a short passage.

Unavailable: start Kokoro and check the configured address/port.
Busy: finish or cancel the recording being generated, then retry.
Speech failure: check service-error.log in the installed folder. Include the
service revision, browser version and steps when requesting help. Do not send
private reading material, passwords, medical details or other sensitive data.
